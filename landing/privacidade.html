A tua privacidade é importante para nós. Esta Política explica de forma clara que dados recolhemos, como os utilizamos e quais são os teus direitos ao abrigo do Regulamento Geral sobre a Proteção de Dados (RGPD).

1. Responsável pelo Tratamento

O responsável pelo tratamento dos teus dados pessoais é a Loyalle, empresa registada em Portugal. Para questões de privacidade, podes contactar-nos em privacidade@loyalle.pt.

2. Dados que Recolhemos

Recolhemos diferentes categorias de dados consoante a forma como interages com a Loyalle:

2.1 Dados de Utilizadores (negócios):

  • Nome e apelido
  • Endereço de email
  • Nome e informações do negócio (logo, cores, nome da loja)
  • Dados de faturação (processados pela Stripe — não armazenamos dados de cartão)
  • Registos de acesso e utilização da plataforma
  • Comunicações trocadas com o nosso suporte

2.2 Dados de Clientes Finais (portadores de cartão):

  • Identificador único do dispositivo (gerado automaticamente)
  • Número de visitas e carimbos acumulados
  • Data e hora das interações com o cartão
  • Token de push notification (com consentimento)

Nota: Os dados dos Clientes Finais são tratados em nome do Utilizador (negócio), que é o responsável pelo tratamento desses dados perante os seus clientes.

2.3 Dados técnicos recolhidos automaticamente:

  • Endereço IP
  • Tipo e versão do browser
  • Sistema operativo
  • Páginas visitadas e tempo de sessão
  • Origem do tráfego

4. Retenção de Dados

Conservamos os teus dados apenas pelo tempo necessário para as finalidades que os justificam:

  • Dados de conta ativa: durante toda a duração da subscrição
  • Dados após cancelamento: 30 dias para possível reativação, depois eliminados
  • Dados de faturação: 10 anos (obrigação legal fiscal)
  • Registos de acesso: 12 meses
  • Comunicações de suporte: 3 anos
  • Dados de Clientes Finais: conforme definido pelo Utilizador, eliminados com a conta

5. Partilha de Dados

Não vendemos os teus dados a terceiros. Partilhamos dados apenas com:

  • Stripe — processamento de pagamentos (sujeito à Política de Privacidade da Stripe)
  • Apple — distribuição de passes Apple Wallet
  • Google — distribuição de passes Google Wallet
  • Fornecedores de infraestrutura cloud — alojamento e base de dados (dentro da UE)
  • Ferramentas de analytics — com dados anonimizados ou pseudonimizados
  • Autoridades competentes — quando exigido por lei

Todos os subcontratantes são selecionados com base em garantias adequadas de proteção de dados e estão vinculados a acordos de tratamento de dados.

6. Transferências Internacionais

Os teus dados são processados principalmente dentro da União Europeia. Quando transferimos dados para países terceiros (como EUA, no caso da Stripe), garantimos que essas transferências estão protegidas por mecanismos adequados, nomeadamente as Cláusulas Contratuais Tipo aprovadas pela Comissão Europeia.

7. Os Teus Direitos

Ao abrigo do RGPD, tens os seguintes direitos:

👁️
Acesso
Podes solicitar uma cópia dos dados pessoais que temos sobre ti.
✏️
Retificação
Podes corrigir dados incorretos ou incompletos.
🗑️
Eliminação
Podes solicitar a eliminação dos teus dados ("direito ao esquecimento").
⏸️
Limitação
Podes solicitar a suspensão do tratamento em determinadas circunstâncias.
📦
Portabilidade
Podes receber os teus dados num formato estruturado e legível por máquina.
🚫
Oposição
Podes opor-te ao tratamento baseado em interesse legítimo ou marketing direto.

Para exercer qualquer destes direitos, contacta-nos em privacidade@loyalle.pt. Respondemos no prazo máximo de 30 dias.

Se considerares que os teus direitos foram violados, podes apresentar reclamação à Comissão Nacional de Proteção de Dados (CNPD).

8. Cookies

O nosso site e plataforma utilizam cookies para o correto funcionamento do serviço e melhoria da experiência. Os tipos de cookies utilizados são:

  • Cookies essenciais: necessários para o funcionamento do serviço (sessão, autenticação). Não podem ser desativados.
  • Cookies de preferências: guardam as tuas preferências (como a língua selecionada).
  • Cookies de analytics: utilizados para compreender como o serviço é utilizado, com dados anonimizados. Requerem consentimento.

Podes gerir as tuas preferências de cookies através das definições do teu browser ou da nossa ferramenta de consentimento.

9. Segurança

Adotamos medidas técnicas e organizativas adequadas para proteger os teus dados, incluindo:

  • Encriptação de dados em trânsito (TLS/HTTPS)
  • Encriptação de dados em repouso
  • Controlo de acesso baseado em funções (RBAC)
  • Monitorização contínua de segurança
  • Backups regulares e testados
  • Política de gestão de incidentes de segurança

Em caso de violação de dados com impacto nos teus direitos, notificamos a CNPD no prazo de 72 horas e, se necessário, os próprios afetados.

10. Menores

A Loyalle não recolhe intencionalmente dados pessoais de menores de 16 anos. Se tomares conhecimento de que um menor forneceu dados pessoais sem consentimento parental, contacta-nos para que possamos eliminar essas informações.

11. Alterações à Política

Podemos atualizar esta Política de Privacidade periodicamente. Quando o fizermos, notificamos por email com pelo menos 15 dias de antecedência em caso de alterações materiais. A data da última atualização é sempre indicada no topo do documento.

12. Contacto e DPO

Para qualquer questão relacionada com a proteção de dados ou para exerceres os teus direitos:

  • Email: privacidade@loyalle.pt
  • Instagram: @loyalle.pt

Comprometemo-nos a responder a todas as solicitações no prazo máximo de 30 dias após a receção.
